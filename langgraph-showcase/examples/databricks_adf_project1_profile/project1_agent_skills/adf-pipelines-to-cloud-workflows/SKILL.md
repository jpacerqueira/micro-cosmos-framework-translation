# ADF Pipelines → Cloud Workflows

## ADF file format expected by db2bq

db2bq reads from `adf/` relative to the source root:

```
adf/
  pipeline_MainETLPipeline.json
  pipeline_PaymentPipeline.json
  trigger_daily_schedule.json
  trigger_payment_hourly.json
```

### Pipeline JSON structure

```json
{
    "name": "MainETLPipeline",
    "properties": {
        "activities": [
            {
                "name": "IngestNmItemSupplier",
                "type": "DatabricksNotebook",
                "typeProperties": {
                    "notebookPath": "/Repos/retail-platform/notebooks/03_etl_jobs/RunETLPipeline",
                    "baseParameters": {
                        "table_name": "nm_item_supplier",
                        "run_mode": "full"
                    }
                }
            },
            {
                "name": "RunScript",
                "type": "DatabricksSparkPython",
                "typeProperties": {
                    "pythonFile": "dbfs:/FileStore/scripts/ingest_item_season.py",
                    "parameters": ["--table", "item_season"]
                }
            },
            {
                "name": "RunJar",
                "type": "DatabricksSparkJar",
                "typeProperties": {
                    "mainClassName": "com.retail.KlarnaReconciliation"
                }
            }
        ]
    }
}
```

### Trigger JSON structure

```json
{
    "name": "DailyETLTrigger",
    "properties": {
        "type": "ScheduleTrigger",
        "typeProperties": {
            "recurrence": {
                "frequency": "Day",
                "interval": 1,
                "timeZone": "UTC",
                "schedule": {
                    "hours": [2],
                    "minutes": [0]
                }
            }
        },
        "pipelines": [
            {
                "pipelineReference": {
                    "referenceName": "MainETLPipeline"
                }
            }
        ]
    }
}
```

## What db2bq produces from ADF files

| ADF artefact | GCP output |
|---|---|
| `DatabricksNotebook` activity | DataProc job step in Cloud Workflows YAML |
| `DatabricksSparkPython` activity | DataProc PySpark job step |
| `DatabricksSparkJar` activity | DataProc Spark jar job step (TODO annotation) |
| `ScheduleTrigger` daily | Cloud Scheduler job JSON + Workflows trigger |
| `ScheduleTrigger` hourly | Cloud Scheduler job (hourly cron) |

## Cloud Workflows YAML shape

```yaml
# Auto-generated by db2bq from adf/pipeline_MainETLPipeline.json
main:
  params: [args]
  steps:
    - IngestNmItemSupplier:
        call: http.post
        args:
          url: ${"https://dataproc.googleapis.com/v1/projects/" + args.project + "/regions/" + args.region + "/jobs:submit"}
          auth:
            type: OAuth2
          body:
            reference:
              projectId: ${args.project}
            placement:
              clusterName: ${args.cluster}
            pysparkJob:
              mainPythonFileUri: ${args.scripts_bucket + "/notebook_RunETLPipeline.py"}
              args:
                - "--table-name"
                - "nm_item_supplier"
                - "--run-mode"
                - "full"
        result: job_result

    - RunBISAnalytics:
        call: http.post
        args:
          url: ${"https://dataproc.googleapis.com/v1/projects/" + args.project + "/regions/" + args.region + "/jobs:submit"}
          auth:
            type: OAuth2
          body:
            pysparkJob:
              mainPythonFileUri: ${args.scripts_bucket + "/notebook_BISAnalytics.py"}
              args:
                - "--season-code"
                - "AW24"
        result: bis_result
```

## Cloud Scheduler job (from trigger)

```json
{
  "name": "projects/my-project/locations/europe-west2/jobs/daily-etl-trigger",
  "schedule": "0 2 * * *",
  "timeZone": "UTC",
  "httpTarget": {
    "uri": "https://workflowexecutions.googleapis.com/v1/projects/my-project/locations/europe-west2/workflows/MainETLPipeline/executions",
    "httpMethod": "POST",
    "body": "eyJhcmd1bWVudCI6ICJ7fSJ9",
    "oauthToken": {
      "serviceAccountEmail": "scheduler-sa@my-project.iam.gserviceaccount.com"
    }
  }
}
```

## Activity type mapping

| ADF type | DataProc GCP equivalent | Notes |
|---|---|---|
| `DatabricksNotebook` | `pysparkJob` with translated notebook | Notebook translated to `.py` by db2bq |
| `DatabricksSparkPython` | `pysparkJob` | Python file path mapped from DBFS |
| `DatabricksSparkJar` | `sparkJob` | JAR path mapped from DBFS; needs JAR rebuild on GCP |

## Dependency ordering

ADF `dependsOn` → Cloud Workflows sequential step ordering:

```json
"dependsOn": [{"activity": "IngestNmItemSupplier", "dependencyConditions": ["Succeeded"]}]
```

→ In Cloud Workflows: place `RunBISAnalytics` step after `IngestNmItemSupplier` step.

## Checklist

- [ ] Create `adf/pipeline_*.json` and `adf/trigger_*.json` files before running db2bq
- [ ] Verify notebookPath values match the notebook files in `notebooks/`
- [ ] Map DBFS paths (`dbfs:/FileStore/...`) to GCS URIs in `--mount-mapping`
- [ ] Create Cloud Scheduler SA with `roles/workflows.invoker`
- [ ] Create Workflows execution SA with `roles/dataproc.editor`
- [ ] Replace ADF Linked Services with Dataproc cluster/serverless config vars
