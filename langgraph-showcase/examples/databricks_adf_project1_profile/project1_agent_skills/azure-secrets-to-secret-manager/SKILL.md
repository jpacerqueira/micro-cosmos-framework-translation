# Azure Secrets → GCP Secret Manager

## What db2bq detects

db2bq scans source files for:
- `dbutils.secrets.get(scope="...", key="...")` — Databricks secret scope references
- Azure SDK patterns: `SecretClient(...).get_secret("...")`
- `local.settings.json` — Azure Functions app settings with `@Microsoft.KeyVault(...)` references

For this project, detected references from `azure_functions/local.settings.json`:
- Vault: `retailkv`, Secret: `EVENT-GRID-ACCESS-KEY`

## Secret naming convention

db2bq uses deterministic IDs: `akv__<vault>__<secret-name>` (lowercase, `--` → `__`):

| Azure | GCP Secret Manager ID |
|---|---|
| Vault `retailkv`, key `EVENT-GRID-ACCESS-KEY` | `akv__retailkv__event_grid_access_key` |
| Databricks scope `my-scope`, key `db-password` | `dbx__my_scope__db_password` |

## Mirror command (cutover step)

```bash
# Step 1: Read from Azure Key Vault
SECRET_VALUE=$(az keyvault secret show \
  --vault-name retailkv \
  --name EVENT-GRID-ACCESS-KEY \
  --query value -o tsv)

# Step 2: Write to GCP Secret Manager
echo -n "$SECRET_VALUE" | gcloud secrets versions add \
  akv__retailkv__event_grid_access_key \
  --project=my-gcp-project \
  --data-file=-
```

## Call-site rewrite pattern

**Before (Azure Key Vault):**
```python
from azure.keyvault.secrets import SecretClient
from azure.identity import DefaultAzureCredential

client = SecretClient(vault_url="https://retailkv.vault.azure.net/", credential=DefaultAzureCredential())
access_key = client.get_secret("EVENT-GRID-ACCESS-KEY").value
```

**After (GCP Secret Manager):**
```python
from google.cloud import secretmanager

def get_secret(project_id: str, secret_id: str, version: str = "latest") -> str:
    client = secretmanager.SecretManagerServiceClient()
    name = f"projects/{project_id}/secrets/{secret_id}/versions/{version}"
    response = client.access_secret_version(name=name)
    return response.payload.data.decode("UTF-8")

access_key = get_secret("my-gcp-project", "akv__retailkv__event_grid_access_key")
```

**Before (Databricks secret scope):**
```python
access_key = dbutils.secrets.get(scope="my-scope", key="event-grid-key")
```

**After:**
```python
access_key = get_secret("my-gcp-project", "dbx__my_scope__event_grid_key")
```

## IAM — grant runtime SA access

Grant per-secret, not project-wide (minimise blast radius):

```bash
gcloud secrets add-iam-policy-binding akv__retailkv__event_grid_access_key \
  --project=my-gcp-project \
  --member="serviceAccount:cloudrun-sa@my-gcp-project.iam.gserviceaccount.com" \
  --role="roles/secretmanager.secretAccessor"
```
