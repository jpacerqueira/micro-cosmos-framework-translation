BankXYZ Fraud Detection API — cURL Examples
===========================================
Base URL: http://localhost:8080/api/v1

All requests use Content-Type: application/json.
The API is identical for both the Java and C# implementations.


---------------------------------------------------------------------------
Scenario 1: Low-risk ChipPin transaction (APPROVE expected)
  Account: ACC0000001 (John Smith, active)
  Merchant: MCH00001 (LOW risk)
  Amount: £49.99 (below low threshold)
  Channel: CHIPPIN (profile weight zeroed)
  Expected score: ~0.09-0.15
---------------------------------------------------------------------------
curl -s -X POST http://localhost:8080/api/v1/authorise \
  -H "Content-Type: application/json" \
  -d '{
    "txnId":        "TXN0000000000001",
    "acctNo":       "ACC0000001",
    "txnAmount":    49.99,
    "merchantCode": "MCH00001",
    "channel":      "CHIPPIN",
    "txnCountry":   "GBR",
    "cardType":     "VI",
    "cnpFlag":      false
  }'

Expected response:
{
  "txnId":      "TXN0000000000001",
  "decision":   "APPROVE",
  "returnCode": "00",
  "fraudScore": 0.1000,
  "message":    "TRANSACTION APPROVED",
  "elapsedMs":  12
}

Scenario 2: High-value CNP transaction in unusual country (REVIEW/DECLINE)
  Account: ACC0000002 (Jane Doe, active, usual country GBR)
  Merchant: MCH00002 (HIGH risk)
  Amount: £7500 (above high threshold)
  Channel: ONLINE
  Country: USA (differs from profile)
  CNP: true

  Processes all pending TXN_QUEUE records (TXN_STATUS = 'P').
  Normal schedule: daily at 02:00 local time.
---------------------------------------------------------------------------

Expected response:
{
  "message": "Batch complete: 0 processed, 0 alerts raised in 3ms"
}
